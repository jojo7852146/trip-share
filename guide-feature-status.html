📍 现在怎么用

  1. 浏览器打开 http://localhost:8000
  2. 登录（已有 demo 账号 demo / demo123456，或注册自己的）
  3. 点顶部的 📚 攻略 标签 → 创建/打开一本攻略
  4. 在攻略详情页右上角点 🎨 翻页 切到杂志视图
  5. 点 📤 导出 ▾：
    • 导出为 PDF：浏览器打印 → 另存为 PDF（背景图形要打勾！）
    • 复制 Markdown：粘到 Notion / 语雀 / 博客
    • 开启公开链接：生成 /p/xxx，任何人凭链接就能看
💡 导出 PDF 的小提示
Chrome 打印对话框里把 "更多设置 → 背景图形" 勾上，否则封面渐变和章节左侧紫条会丢失。这是浏览器默认安全策略，不是 bug。
